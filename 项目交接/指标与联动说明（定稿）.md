## 先看结论：这批货能不能养活自己

**按现在的设定，4,000 件全部卖完、付清货款和头程后，只剩约 $3,600 可以用来投广告和养团队；前 11 天广告已经花了 $18,015。** 账期只是把付款往后推，不会变出钱来。

| 每件 | 金额 | 4,000 件合计 |
| --- | --- | --- |
| 回款（扣广告前） | $10.54 | $42,160 |
| 货值 | $8.51 | $34,030 |
| 头程（快船） | $1.12 | $4,495 |
| **剩下给广告 + 团队** | **$0.91** | **约 $3,600** |

| --- | --- | --- | --- | --- |
| 30%（现状） | $22.79 | $0.91 / $0.32 | $3,640 / $1,280 | 4.0% / 1.4% |
| 20% | $25.19 | $2.65 / $2.06 | $10,600 / $8,240 | 10.5% / 8.2% |
| 不开 | $29.99 | $6.73 / $6.14 | $26,920 / $24,560 | 22.4% / 20.5% |

11 月 7 日到 1 月 14 日是旺季，这批货大部分在旺季卖，应该看旺季那一栏。想给团队留钱，主要靠降 coupon，不是靠调推广节奏。

**用账期养团队，实际是在向工厂滚动借钱**：用第二批账期内的回款去付第一批的货款，以此类推。要让这笔借款不越滚越大，条件是：每月卖出件数 × 每件剩的钱（扣完广告）≥ 每月团队开支。比如旺季 coupon 20% 时每件剩 $2.06，团队每月若要 $10,000，每月就得卖约 4,900 件。风险是：工厂一旦不给下一批账期，滚动中欠的钱会一次到期；如果广告把每件吃成负数，团队现在花的每一块都是以后要还的。

**库存撑不到补货**：按 11 月 17 日之后每天 200 单，剩下 3,151 件约 12 月 3 日卖空。补货要做货 5 周 + 美森 4 周，约 9 周，所以不提前下单就会断货，第二批的货款和账期也要算进来。

还有一个未知数可能把结论变得更差：头程 ¥14/kg 含不含关税。见下面账本和第七节。

**运营要交付的结果**

| 要回答的问题 | 工具给出的结果 |
| --- | --- |
| 推广多大力度、持续多久？ | 每周广告预算、持续周数、什么情况下加大或收缩 |
| 钱哪天真正到账？ | 每周预计到银行的金额，分成未结算、已结算、已到账 |
| 前期最多要垫多少？ | 整个计划里的最低余额和发生日期 |
| 每月能给团队多少？ | 每月可拨给团队的金额、能覆盖几个月开支 |
| 工厂到期时付得清吗？ | 每笔货款到期日的余额和缺口 |
| 最后经营结果怎样？ | 付清货款和开支后的剩余现金、利润、剩余库存 |

**方案对比：价格档 × 推广节奏**：决定能不能付清货款的，首先是 coupon 和售价（每件剩多少），其次才是推广快慢。所以按 2–3 个价格档（比如 coupon 30% / 20% / 不开）乘"缓推 / 适中 / 快推"来比。每个方案除了上面 6 个结果，还要给出：断货日、什么时候补货和用什么运输、第二批货的账期；反推的每单广告费上限；止损线，比如连续两周 TACOS 超过某个值或单量没到某个数就收缩。缓推省广告，但库存放得久、仓储费更高，到期时也可能不够付。

**广告假设要单独看待**：CPC、转化率、单量都是手填的目标。工具能算"要卖这么多，得花多少广告费"，但不能证明"花了就能卖这么多"。上线后要每周用实际投放数据替换假设。

## 三、计划细节表：每天一行（核心）

每天填 8 个数，表格算出当天的广告费、回款和毛利。现在只填了 11 天（2026-11-07 到 11-17）。计算分四步：**成交价 → 广告费 → 平台扣费 → 回款和毛利**。

**运营每天填的**

| 指标 | 现在的值 | 说明 |
| --- | --- | --- |
| 前台售价 | $29.99 | 标价 |
| prime 折扣 | 空（0） | 隐藏列 |
| coupon | 30% | 折扣力度 |
| coupon 使用率 | 80% | 隐藏列；备注写的是 60% |
| prime 折扣使用率 | 90% | 隐藏列；没开 prime 折扣时不起作用 |
| CPC | $7 逐步降到 $3.4 | 每次点击的价 |
| CVR | 12% | 广告转化率 |
| 总单量 | 3 单涨到 200 单 | 当天计划卖多少 |
| 广告单占比 | 100% 降到 60% | 有多少单靠广告 |

CTR（1%）也填了，但没有任何公式用它。

**第 1 步：成交价**

| 指标 | 公式 | 例（$29.99） |
| --- | --- | --- |
| 最低成交价 | 售价 × (1 − coupon) × (1 − prime 折扣) | $20.99 |
| 平均成交价 | 售价 × (1 − coupon × 使用率) × (1 − prime 折扣 × 使用率) | $22.79 |
| 总销售额 | 总单量 × 平均成交价 |  |

**第 2 步：广告**

| 指标 | 公式 |
| --- | --- |
| 广告单 | 总单量 × 广告单占比 |
| 自然单 | 总单量 − 广告单 |
| CPA（每个广告单的成本） | CPC ÷ CVR，例如 $7 ÷ 12% = $58 |
| 广告花费 | CPA × 广告单 |
| ACOS | 广告花费 ÷ 广告单销售额 |
| TACOS | 广告花费 ÷ 总销售额 |

**第 3 步：平台每单扣的钱**

| 指标 | 公式 |
| --- | --- |
| 佣金（表头写"FBA佣金17%"） | 按"用券/不用券 × 用 prime/不用"四种情况各自的成交价分档收 5%/10%/17%（最低 $0.30），再按使用率加权平均 |
| FBA 配送费、入库配置费、仓储费 | 取利润数据表 |
| 退货损失 | 平均成交价 × 8%（表头写 10%） |
| coupon 单数 | 总单量 × coupon 使用率 |
| coupon 手续费 | 券后价 × coupon 单数 × 2.5% |
| 货值 | 取利润数据表（$8.51） |
| 头程 | 取汇总表 M21：所有计划发货的平均每件头程（现在 $1.12） |

**第 4 步：回款和毛利**

| 指标 | 公式 |
| --- | --- |
| 回款（不扣广告） | 销售额 − coupon 费 − 活动费 − (佣金 + FBA + 退货 + 入库 + 承运人 + 仓储) × 单量 |
| 净回款 | 回款 − 广告费。表格把广告费并进这笔钱一起在下单 +25 天到账，实际广告费的出账时间见前面账本里的广告费一行 |
| 单价回款 / 不垫钱 CPA | 回款 ÷ 单量（两列一模一样） |
| 订单毛利 | 净回款 − (货值 + 头程) × 单量 |
| 回款日期 | 下单日 + 25 天 |
| 回款月份 | 回款日期所在的月 |

## 五、备货计划和目标汇总表

**备货计划**按周排（周一到周日），运营只填两列：每周发多少海运、多少空运。

| 指标 | 公式 |
| --- | --- |
| 年月、周起止、该周天数 | 从计划细节表第一天开始自动排 |
| 预计销量 | 把计划细节表这一周的单量加起来 |
| 在途-美森 / 在途-空运 | **手填**，表示这周第一天发出 |
| 预计到货数量 | 应该是"4 周前发的美森 + 2 周前发的空运"，现在整列空着 |
| 剩余库存 | 上周库存 − 本周销量 + 本周到货；第一格没接首批 4,000 件，所以一路是负数 |
| 让工厂备货 | 5 周后要发的货（美森 + 空运），就是这周要下单的量（做货 5 周） |

备货表只有"在途"两列被别的表用：汇总表按月加起来算发货花的钱。库存几列只是自己看。

**目标汇总表**是横版看板，每列一个月，全部从汇总表搬数：目标单量、销售额、日均单量、增幅、广告花费、TACOS、货值、头程、回款、利润率、利润、两个"是否覆盖"。它不自己算任何东西，但现在有几格是空的或手打的旧数字（2026 年 12 月整列、以及 2027 年的货值头程和回款）。

## 六、指标联动

数据基本是从上往下流，只有一条回头线：备货表里排的所有发货算出平均每件头程，再喂回每一天的毛利。所以以后多排一批空运，已经过去的 11 月毛利也会跟着变。

（原文此处有一张图：五张表的数据流向 · 一条回头线。图未能导出，文字说明见本节上下文。）

**改一个输入，会动哪些结果**

| 改这个 | 直接变的 | 最后影响到 |
| --- | --- | --- |
| coupon 力度或使用率 | 平均成交价、佣金、coupon 费、退货损失 | 每件利润、回款、月利润、账上余额。影响最大：30%→20% 每件不含广告利润从 $0.91 升到 $2.65 |
| 售价 | 成交价、佣金档位、退货损失 | 同上 |
| CPC 或 CVR | CPA、广告花费、ACOS/TACOS | 净回款、毛利、账上余额 |
| 单量、广告单占比 | 广告单数、广告费、销售额 | 周/月汇总、回款、备货表的预计销量 |
| 进价、汇率 | 货值 $ | 每天毛利，以及每月发货要付的货款 |
| 尺寸、重量 | 空运/快船头程单价 | 发货花的钱 → 平均头程 M21 → 每天毛利 |
| FBA 配送费、仓储费 | 每单平台扣费 | 回款、毛利 |
| 备货表的发货量 | 当月发货花的钱 | 账上余额、是否覆盖；另外通过 M21 改每天毛利 |
| 回款天数（25 天） | 回款日期、回款月份 | 哪个月收到钱、账上最低余额。利润总数不变 |

记住两个口径：**按下单月**算的是这个月做了多少生意；**按回款月**算的是这个月卡上到了多少钱。现金流只看后一个。

## 七、需要你确认的问题

这些决定算法怎么定，直接在后面写答案或者评论就行。

**先请你一次填完这几个数**（现金流的起点和必须付的钱）：

1. 现在能周转的现金有多少？
2. 团队每月必须开支多少、哪几天付？
3. 工厂：未付金额多少、到期日是哪天、固定日期付还是按卖出结算、第二批是否同样有账期？
4. 现有可售库存和在途库存各多少？

**最优先：头程 ¥14/kg 含不含关税（包税）？** 服装从中国进美国的关税可能每件好几美元，比现在每件 $0.91 的剩余还大。没确认前，前面的结论都可能更差。

**偏乐观、要用实际数据核实的假设**：转化率 12%、11 天内自然单涨到 40%、退货率 8%、11 月旺季的 CPC。

其他问题：

1. 退货率按 8% 还是 10%？仓储费按"每卖一件 $0.09"还是按库存放多久算？
2. coupon 使用率按 80% 还是备注里的 60%？30% 的 coupon 是整个推广期都开，还是只有前期？
3. 回款周期按"下单后 25 天"，还是按备注里的"DD+7、14/28 号回款、再晚一个月"？
4. 广告费是从回款里扣，还是信用卡另付？如果是信用卡，还款日是哪天？
5. FBA 配送费要不要分淡旺季（11 月到 1 月 14 日约 $6.63）？
6. 汇率统一用哪个数？
7. 首批 4,000 件在 11 月 7 日前已经全部入仓了吗？要不要作为备货表的起始库存？
8. "覆盖未来 3 个月"这个判断你平时真的用吗？你最想看的现金指标是哪个：账上最低余额、什么时候回正，还是覆盖与否？
