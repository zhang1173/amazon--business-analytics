# 推广计划表工具（第二代）

把用户的 Excel《Y背三件套内衣-现金流-推广计划+利润表》搬成网页：运营按日填推广计划，工具算回款、毛利，往下汇总到周 / 月 / 纯现金流 / 资金盘 / 全年表；另有独立的「出方案」功能，工具按参数生成几套方案，和运营的方案并排对比。不排名、不推荐、不给红绿灯。

- 在线版：https://claude.ai/artifact/ThBASVeKg4kgniRuHU2t1d
- 方案稿（用户 2026-11-01 核对通过）：https://claude.ai/artifact/68bFEDpsgyE2NQhXvcupVz ，文字版见 `../推广计划表工具方案稿.md`

## 文件

| 文件 | 是什么 |
| --- | --- |
| `model.js` | 计算核心（纯函数）：日表公式照 Excel；汇总、纯现金流、资金盘（DD+7 + 14/28 号结算）、全年表、方案对比、出方案、Excel 粘贴解析 |
| `ui.js` | 网页界面（只显示和输入，计算全调 model.js） |
| `page.html` | 样式和外壳，`build.py` 把 model.js / ui.js 拼进去 |
| `build.py` | 出 `build/推广计划表.html`（发布用）和 `build/推广计划表（可直接打开）.html`（双击就能用） |
| `test_model.js` | 计算核心自检：原表格口径下 11/7 起 11 天每一列对 Excel（`excel_ref.json`），共 363 项 |
| `e2e.js` | 浏览器自检（Playwright）：改数、倒推广告单占比、加天、递增率生成、粘贴、各页、导出 Excel、手机宽度 |
| `excel_ref.json` | 从用户 Excel 读出来的缓存值（对数用） |

## 自检

```
node test_model.js          # 363/363 checks passed
python3 build.py
node e2e.js                 # 没网时：XLSX_LIB=…/xlsx.full.min.js XLSX_PKG=…/xlsx node e2e.js
```

## 口径要点

- 两套费率：财务包口径（默认，FBA $6.50、退货 10% + $3、仓储 $0.11，货值头程按发货批次 FIFO）；原表格口径（FBA $6.04、退货 8%、仓储 $0.09、货值 $8.51 + 头程 $1.12，只用来对 Excel）。
- 广告花费 = CPA × 广告单（CPA = CPC ÷ CVR），广告单占比是输入；在网页里直接改广告花费会倒推占比。
- 库存 = 已到货批次数量 − 累计单量，卖完后的单不算回款（标「断货」）。
- 日表回款日期 = 下单 + 25 天；资金盘：送达（+2）→ 释放（+7）→ 结算日（默认每月 14 / 28 号）打款扣当期广告 → +5 天到账；当期广告比回款多时差额当天算信用卡付。口径 B「按需提现」= 释放 + 5 天到账、广告当天付。
- 固定开支每月 15 号 ¥70,000；货款发货后 6 个月、头程 60 天到期。
- 数据存在浏览器 localStorage（键 `promo-plan-v2`），可导出 / 导入方案文件（JSON）。
